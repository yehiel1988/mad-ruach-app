# Periodly — אפליקציה לפלאפון

אפליקציית PWA: מתקינים למסך הבית, נפתחת במסך מלא בלי שורת דפדפן, ועובדת גם בלי אינטרנט.

## הקבצים
| קובץ | מה זה |
|---|---|
| `index.html` | האפליקציה עצמה |
| `manifest.webmanifest` | שם, צבעים ואייקונים להתקנה |
| `sw.js` | Service Worker — שמירה במטמון לעבודה אופליין |
| `icon-192.png`, `icon-512.png`, `icon-maskable.png` | אייקוני האפליקציה |

## איך מעלים לאוויר (2 דקות, בחינם)

**האפשרות הכי מהירה — Netlify Drop**
1. נכנסים ל־https://app.netlify.com/drop
2. גוררים לשם את **התיקייה כולה** (לא רק ה־HTML)
3. מקבלים כתובת כמו `https://mad-ruach.netlify.app` — זהו

**חלופה — GitHub Pages**
1. יוצרים ריפו חדש ומעלים אליו את כל הקבצים
2. Settings → Pages → Source: `main` / תיקיית root
3. הכתובת תהיה `https://<שם-משתמש>.github.io/<שם-ריפו>/`

חשוב: ההתקנה למסך הבית והעבודה האופליין דורשות **https**. פתיחה של הקובץ ישירות מהטלפון (`file://`) תעבוד, אבל בלי אייקון ובלי מסך מלא.

## איך מתקינים בטלפון

**אייפון (Safari — חובה Safari, לא כרום)**
1. פותחים את הכתובת
2. כפתור השיתוף (הריבוע עם החץ) → **הוספה למסך הבית**
3. האייקון יופיע כמו כל אפליקציה אחרת

**אנדרואיד (Chrome)**
1. פותחים את הכתובת
2. תופיע הצעת **התקנה**, או: תפריט שלוש הנקודות → **התקנת אפליקציה**

## עדכון האפליקציה
אחרי כל שינוי בקבצים, מעלים מחדש ומשנים את השורה `const CACHE = 'mad-ruach-v1'` בקובץ `sw.js` ל־`v2` וכן הלאה. בלי זה הטלפון ימשיך להציג את הגרסה הישנה מהמטמון.
